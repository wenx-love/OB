手动断点模式验证

验证目标

确认 OB-Recover 的手动断点模式能够：

  1. 不自动设置任何断点
  2. 接收用户在 Sources 面板手动设置的断点触发的暂停事件
  3. 读取暂停上下文（callFrames、局部变量）
  4. 不干扰用户的调试流程（不自动 resume）

验证步骤

1. 确认扩展已加载
  • 打开 DevTools（F12）
  • 切换到 OB-Recover 标签
  • 点击「连接调试器」
  • 确认模式显示为「手动断点模式」
2. 在 Sources 面板设置断点
  • 切换到 Sources 标签
  • 找到本页面的 manual-mode-test.html
  • 在下面的 testFunction1 第一行设置断点
3. 触发断点

点击按钮后，应该暂停在你设置的断点处

4. 检查 OB-Recover 面板
  • 切换到 OB-Recover 标签
  • 应该能看到「手动捕获记录」
  • 包含当前暂停位置、函数名等信息
5. 继续调试
  • 返回 Sources 标签
  • 按 F8 或点击「继续」按钮
  • 应该能正常继续执行
