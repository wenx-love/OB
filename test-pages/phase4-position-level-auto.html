Phase 4 位置级替换验收页面（自动化版本）

📋 测试目标

验证系统能够根据 scriptId + scriptHash + start/end 定位具体 AST 节点，而非全局文本替换。

🎯 测试场景

场景 1：不同参数不同结果

源码中有 3 个对同一函数的调用，但参数不同：

  • 位置 A (第 26 行)：_0x123456(0x10) → 应替换为 "Signature"
  • 位置 B (第 30 行)：_0x123456(0x11) → 保留原样（参数不同）
  • 位置 C (第 34 行)：_0x123456(0x10) → 应替换为 "Signature"

场景 2：冲突证据拒绝

调用 _0xabcdef(0x20) 两次，返回不同值：

  • 位置 D1 (第 42 行)：返回 "Conflict1" → 应拒绝替换
  • 位置 D2 (第 43 行)：返回 "Conflict2" → 应拒绝替换

✅ 验收标准

应用替换后，还原代码应该是：

var resultA = "Signature";        // ✅ 已替换 (0x10 → "Signature")
var resultB = _0x123456(0x11);   // ✅ 保留原样（参数 0x11 ≠ 0x10）
var resultC = "Signature";        // ✅ 已替换 (0x10 → "Signature")
var resultD1 = _0xabcdef(0x20);  // ✅ 拒绝替换（冲突）
var resultD2 = _0xabcdef(0x20);  // ✅ 拒绝替换（冲突）
