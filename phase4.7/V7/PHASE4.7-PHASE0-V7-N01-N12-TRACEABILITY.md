# OB-Recover Phase 4.7：Phase 0 V7 对第九轮 V6-N01—N12 的逐项追溯

日期：2026-11-11。性质：契约追溯，不是独立复核结论。每项给出：原始问题、根因、修改位置、修复后规则、独立验证方法、实际验证结果、剩余风险、是否需动态测试。

## N01 读取权限双向交集（P0）

- **原始问题：** C05-FINAL 与 C20-SEAL 各 16 处、共 32 处 allow/deny 交集；检测只查单向。
- **根因：** `denyFor` 未把 `T:RUN\tools` 当覆盖；检查器的包含判断只考虑 allow 在 deny 之下。
- **修改位置：** `p0v7-build.cjs` `denyFor`/`intersects`；`p0v7-check.cjs` 双向扫描与 FINAL/SEAL 断言。
- **修复后规则：** 同一层 allow 与 deny 双向不相交；子树许可覆盖其下全部文件；FINAL/SEAL 不 deny staged 文件。
- **独立验证：** 检查器对 58 执行与产品策略全量扫描，统计交集数。
- **实际结果：** 交集 0（原 32）；FINAL/SEAL 无 staged deny。
- **剩余风险：** 16 文件集合固定，工具包变更需重新生成。
- **动态测试：** 需要（真实 guard 验证路径拒绝/允许）。

## N02 staged 入口 self-read（P1）

- **原始问题：** 16 个 staged 执行的 dispatcher 自读指向 source。
- **根因：** 构建时固定使用 `src('dispatch')`。
- **修改位置：** `p0v7-build.cjs` dispatcher reads；`p0v7-check.cjs` staged self-read 断言。
- **修复后规则：** 自读必须等于 `entry_path`；依赖从同根取。
- **独立验证：** 逐一比较 `reads.dispatcher` 与 `entry_path`。
- **实际结果：** 58/58 一致；16/16 staged 不含 source dispatcher。
- **剩余风险：** 实际“校验字节=加载字节”仍需运行时句柄实现。
- **动态测试：** 需要。
